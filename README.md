# Joyflow POS - Windows Binary Distribution & Auto-Updater

Repository resmi untuk distribusi file instalasi dan pembaruan otomatis (Auto-Updater) **Joyflow POS Windows**.

---

## 📥 Panduan Instalasi di Komputer Kasir

Untuk memasang atau memperbarui Joyflow POS di komputer kasir:

1. **Unduh Launcher**:
   Unduh file **[`JoyflowLauncher.exe`](JoyflowLauncher.exe)** dari repository ini.
2. **Pindahkan ke Folder Aplikasi**:
   Letakkan `JoyflowLauncher.exe` di folder kasir yang diinginkan (contoh: `C:\Joyflow POS\`).
3. **Jalankan Aplikasi**:
   Dobel klik `JoyflowLauncher.exe` (bisa buat *Desktop Shortcut* ke file ini).
4. **Selesai**:
   - Jika ini instalasi pertama atau ada update baru: Launcher otomatis mengunduh dan memasang versi terbaru.
   - Jika sudah versi terbaru: Aplikasi langsung terbuka otomatis dalam hitungan detik.
